Sonicfast is a native desktop client for OpenSubsonic and compatible Subsonic
servers, forked from Spotifast by Carmine Paolino and its contributors.

- Browse and search artists, albums, songs and server playlists.
- Play MP3, FLAC and M4A (AAC-LC/ALAC) with the native output pipeline.
- Create and edit playlists, with confirmation before adding duplicate songs.
- Heart and rate songs; show plain or synchronized lyrics through LRCLIB.
- Enable optional scrobbling and choose listening thresholds.
- Download originals through a background queue and prefer local files for playback.
  Local availability uses filesystem checks without a JSON download index.
- Keep native themes, EQ, visualizers and the Winamp mini-player.

Enter your own server URL and credentials in the native sign-in form.
No Spotify account or subscription is used by the default application.

Linux with Navidrome has native integration coverage. Other platforms, physical
audio hardware and packaged desktop installs need further validation.
Install updates manually; the default client's self-updater is disabled.
Release checksums detect corruption and are not publisher signatures.
