Sonicfast 0.14.2 adds saved server connections and library refresh controls.

- Save multiple OpenSubsonic connections, with one server active at a time.
  Manage, edit and remove them from Settings → Server or the sign-in screen.
- Disconnect without forgetting remembered credentials, then reconnect explicitly.
  Switching connections restores each server's queue paused.
- Use **Sync now** in Settings → Server to refresh the library, playlists and
  current view while playback continues. This refreshes the client; it does not
  start a server-side music scan.
- Remove the Spotify-specific **By You** library filter from the default client.
- Update the connection guide and README with a new native demo screenshot.

Validation: Linux automated tests, native credential storage and saved-connection
flows passed against a synthetic Navidrome library. Multiple profiles were tested
against one server; independent backends, Windows/macOS and physical audio hardware
were not exercised for these changes. Release metadata and packaging regression
checks cover the version bump; packaged desktop installs need further validation.

Install updates manually; the default client's self-updater remains disabled.
